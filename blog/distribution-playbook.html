一个月前，我发布了 aicraft-code-review——一个完全本地运行的 MCP 代码审查服务器（OWASP 安全扫描、N+1 检测、代码风格检查），支持 Claude Code、Cursor 和 Cline。预算：0 元。粉丝：0。

一个月后：PyPI 安装量 650+，Product Hunt 12 个关注者，5 个目录收录，另有 4 个待审。全程没有花一分钱。这篇文章是完整复盘，包括没成功的那部分。

什么真正有效

1. 目录收录会复利

每个目录收录都多一条安装路径、一个外链、以及下一个目录审核时的社交证明。mcpservers.org 一天就过审了，这个收录又让 cursor.directory 的提交更有说服力。

2. Product Hunt 给了我们路线图

我们只有 3 个赞——但两条评论直接变成了下个版本：

  • “希望全队能同步审查规则” → 做了 MCP_CODE_REVIEW_CONFIG 团队共享配置
  • “希望每个仓库有自己的规则集” → 做了 .mcp-code-review.yaml 自动发现

真实用户告诉你该做什么，比任何猜测都值。

3. awesome-mcp-servers 是终极大奖

这个仓库有 92k star，README 是绝大多数人发现 MCP 服务器的方式。但门槛是真的：必须先收录进 Glama 并有质量分数徽章。给审核留出两周时间。

什么没成功（帮你省一周）

Reddit 新号 = 隐形人

两篇 r/mcp 帖子都被静默移除，新号连给版主发私信都不行。教训：在你有东西要推广之前，先在技术板块攒 karma。

HN 是彩票

1 个赞 0 评论。没关系，帖子本身是个永久外链。

付费目录来得早

mcp.so 收 39 美元，OpenTools 只收付费。起步阶段全部跳过。

差点毁掉新装用户的 bug

0.1.0 发布两周后，mcp 2.0.0 带着破坏性 API 变更上线了——新安装我的服务器直接 import 崩溃。原因是我锁了 mcp>=1.6 但没有上限。

如果你今天要发布 Python MCP 服务器：立刻把依赖锁成 mcp>=1.6,<2。

五步打法（可直接抄）

  1. 先发 PyPI/npm。所有其他渠道都会引用你的包。
  2. 一次性备齐通用材料：Dockerfile、LICENSE、SECURITY.md、glama.json、安装文档。每个目录要的都是这些的子集。
  3. 并行投免费目录。快速过审能带起节奏。
  4. 收集反馈并快速发货（PH 评论、issue），然后告诉大家你发货了。
  5. 最后攻两个大 PR：awesome-mcp-servers 和 Docker MCP Registry，等质量分和材料都齐了再上。
