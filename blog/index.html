这篇教程教你在 5 分钟内搭一套 AI Code Review 系统。你只需要：一个 LLM API Key（或者本地模型），和一个终端。

你需要什么

  • Python 3.11+
  • 一个 LLM API Key（OpenAI / Anthropic / Groq 都行）
  • Claude Code / Cursor / Cline 任意一个（免费版即可）

第一步：安装 MCP Code Review Server

一条命令搞定：

pip install aicraft-code-review

这个包自带三个工具：review_code（审查代码片段）、review_diff（审查 Git 变更）、review_file（审查本地文件）。

第二步：配置到你的 AI 客户端

Claude Code

在项目根目录创建 CLAUDE.md，添加：

# MCP 配置
mcp_servers:
  - name: code-review
    command: mcp-code-review

或者直接运行：

claude mcp add code-review -- mcp-code-review

Cursor

在 .cursor/mcp.json 中添加：

{
  "mcpServers": {
    "code-review": {
      "command": "mcp-code-review"
    }
  }
}

Cline (VS Code 插件)

在 Cline 设置中的 MCP Servers 添加：

{
  "mcpServers": {
    "code-review": {
      "command": "mcp-code-review"
    }
  }
}

第三步：开始审查代码

配置好后，你可以在对话中直接使用：

"帮我把这段代码 review 一下"
"审查一下这次 commit 的 diff"
"检查一下 src/main.py 有没有安全问题"

AI 会自动调用 Code Review Server，返回结构化的审查结果，包含：

  • 🔴 严重问题 — 安全漏洞、逻辑错误
  • 🟡 潜在风险 — 性能问题、边界情况
  • 🔵 改进建议 — 代码质量、最佳实践

进阶技巧

结合 CI/CD

你可以把 Code Review Server 集成到 GitHub Actions 中，每次 PR 自动触发审查：

name: AI Code Review
on: [pull_request]
jobs:
  review:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - run: pip install aicraft-code-review
      - run: git diff main...HEAD | mcp-code-review

自定义审查规则

通过 LLM 的系统提示词，你可以自定义审查重点——比如只关注安全漏洞，或者只检查性能问题。
