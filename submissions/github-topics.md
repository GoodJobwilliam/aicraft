# Set GitHub Topics for Auto-Discovery

Several MCP directories (Glama, PulseMCP) auto-discover servers from GitHub topics.

## Action Required

Go to: https://github.com/GoodJobwilliam/aicraft
Click: Settings (top right) → scroll to "Topics"
Add these topics:
- mcp
- model-context-protocol
- code-review
- security
- developer-tools
- python

After adding these, Glama (glama.ai) will auto-index the MCP Code Review Server within 24-48 hours. No manual submission needed.

PulseMCP (pulsemcp.com) will also auto-sync from GitHub.
